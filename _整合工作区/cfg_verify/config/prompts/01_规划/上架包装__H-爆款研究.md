# 上架包装 · 近3个月番茄爆款研究（01_规划）

## 一、任务要求
【任务】研究近 3 个月番茄小说爆款，输出分析报告。

【要求】
1. 选 3-5 本与《疯骨》题材相近的番茄爆款（古言/宫斗/悬疑/大女主/半妖/仵作等）
2. 优先选“第一版书名”状态的书（不是 20 万字后改过的书名）
3. 每本爆款分析以下维度：
   - 【书名拆解】：字数 / 套用的公式 / 前 3 字抛出什么矛盾 / 信息层（题材+身份+爽点）
   - 【简介拆解】：首句钩子类型 / 三段式结构是否完整 / 结尾钩子 / 字数
   - 【受众画像】：男女比例 / 年龄段 / 主要情绪需求（爽感/代入/治愈/虐感）
   - 【爆款原因】：为什么这个书名能吸引点击 / 为什么这个简介能提高转化

【书名四大公式（番茄 2026）】
1. 身份 + 动作 + 反差
2. 重生/穿越 + 强冲突
3. 数字/极端化 + 爽点前置
4. 设定概括 + 数据/结果承诺

【三大书名雷区】
- 文艺抽象型（算法难打标签）
- 设定堆砌型（底牌全亮）
- 跟风蹭字型（同质降权）

## 爆款分析报告
（每本爆款按上述四个维度分析）

（3-5 条可复用的规则）

（3-5 条本作应该遵循的方向）
