# 58 · 上架包装四环标准（书名 / 上架简介 / 标签 / 封面）

> 本文件由 `scripts/export_newskill.py` 从 apps.json / roster.json 自动生成，请勿就地手改；改配置后重跑脚本。

规划程序·上架包装四环执行标准（书名/上架简介/标签选择/封面设计规划）。位置：内容定稿（前30章章纲+开篇爆破+伏笔表）之后、文档与备份之前——内容未定就做包装，设定一漂移包装全废。四环产出物调性必须互相一致（书名硬则封面硬、简介钩子与封面卖点词同源），并统一受第2环「类型平台读者卖点」的平台调性约束。


**顺序**：书名设计(20) → 上架简介(21) → 标签选择(22) → 封面设计规划(23)

## 书名设计　`书名设计`（mesh）

**字段**
- 主书名
- 备选书名×3
- 系列名/可衍生名
- 品类关键词
- 记忆点
- 搜索友好度
- 字数
- 平台调性匹配
- 同名撞车核查

**规则**
- 书名须含品类信号，读者 10 秒内知道这是什么类型。
- 主名 2—6 字为主，易记、易念、易搜。
- 不用生僻字、不用自造词、不用拗口组合（搜不到=没有）。
- 可衍生系列名（第一部火了后面能续）。
- 核查平台同名/近似名，避免撞车与被埋。
- 不剧透结局、不用违规词、不做过头标题党。
- 按目标平台调性校准：番茄偏直白强冲突、起点偏意蕴与设定感、七猫偏强情绪。

**验收**
- [ ] 10 秒内能说清这是什么类型。
- [ ] 读一遍能记住。
- [ ] 搜索框输入能联想出来。
- [ ] 与目标平台调性匹配。
- [ ] 无同名撞车。
- [ ] 无违规词、不剧透。

**常见坑**
- ✗ 文艺到看不出品类。
- ✗ 生僻字导致搜不到。
- ✗ 与爆款撞名被淹没。
- ✗ 剧透结局。
- ✗ 标题党过头，读者点进来就出戏。

## 上架简介　`上架简介`（mesh）
与第 4 环「简介与主题」区分：4 环出内容向简介（常态·变故·行动·悬念），本环出包装向简介，可直接粘贴上架。

**字段**
- 30 字一句话简介
- 80 字短简介
- 300 字标准简介
- 分平台调性版
- 首句钩子
- 卖点词×3
- 主角困境
- 末句悬念

**规则**
- 首句即钩子，前 15 字必须抓人。
- 用主角视角写，不写世界观说明书。
- 动词驱动，少形容词，句子短。
- 末句留悬念（一个问题或未解的局），不写总结。
- 卖点词必须真实存在于正文（虚标=掉推荐+差评）。
- 分平台调性：番茄直白强冲突、起点意蕴+设定感、七猫强情绪。

**验收**
- [ ] 首句抓人（不抓人重写）。
- [ ] 3 秒看完就想点开。
- [ ] 无套话（且不/一路/且看 之类）。
- [ ] 不剧透结局。
- [ ] 可直接粘贴平台简介栏。

**常见坑**
- ✗ 写成世界观说明书。
- ✗ 首句平铺直叙。
- ✗ 剧透结局或关键反转。
- ✗ 套话连篇。
- ✗ 简介与正文卖点不符。

## 标签选择　`标签选择`（human）
AI 出候选组合并说明流量与竞争度，人对照目标平台后台实有标签池核对后定。

**字段**
- 主分类
- 二级分类
- 内容标签×3-5
- 搜索关键词
- 平台标签池核对
- 竞争度
- 流量预估

**规则**
- 每一个标签都必须能在平台后台标签池里找到（不存在=无效）。
- 主分类唯一，不跨品类。
- 内容标签对应真实卖点，不虚标（虚标会被判错放，掉推荐）。
- 3—5 个内容标签，不堆砌。
- 关键词选用户真会搜的词，不是自认为好听的词。

**验收**
- [ ] 每个标签都能在平台后台找到。
- [ ] 标签与正文卖点对得上。
- [ ] 无跨品类错标。
- [ ] 数量在 3—5 个，无堆砌。

**常见坑**
- ✗ 想当然造标签（平台没有）。
- ✗ 跨品类错标（玄幻标成都市）。
- ✗ 堆砌 8 个以上标签。
- ✗ 标签与内容不符导致错放掉量。

## 封面设计规划　`封面设计规划`（mesh）
产出的是设计 brief，供设计师或 AI 生图直接使用，不是直接出图。

**字段**
- 构图
- 主体人物
- 场景元素
- 色调
- 字体层级
- 卖点短词
- 避雷项
- 尺寸规格
- 缩略图可读性

**规则**
- 缩略图尺寸下主体仍可辨（手机书架里只有指甲盖大）。
- 书名占视觉层级第一，卖点短词第二，装饰元素最弱。
- 色调与品类匹配：玄幻偏深金/墨蓝/玄黑，系统与科幻偏科技蓝/冷光，都市偏暖黄/霓虹。
- 卖点短词 ≤6 字，与简介卖点词同源。
- 人物姿态/表情体现调性（无敌流要压迫感，轻松流要松弛）。
- 不用真人照片、不用明星脸、不用未授权素材、不用侵权字体。
- 不出现血腥/暴露/惊悚元素（过不了审）。

**验收**
- [ ] 缩略图下主体清晰可辨。
- [ ] 调性与书名·简介·标签一致。
- [ ] 无侵权素材与侵权字体。
- [ ] 无违规元素（血腥/暴露/惊悚）。
- [ ] brief 可直接交给设计师或 AI 生图。

**常见坑**
- ✗ 缩略图糊成一团看不出主体。
- ✗ 元素过多画面脏。
- ✗ 字体侵权。
- ✗ 封面调性与内容不符（甜美封面配暗黑文）。
- ✗ 用 AI 生成明星脸/真人相。
