## 一、它管什么

- **起跑前选人**：这一本书用哪几台 AI。
- **每个环节可单独覆盖**：四层覆盖 `全局默认 < 按程序 < 按环节 < 按章`，越具体越优先，留空即继承。
- **随时可换**：额度将尽→同档位替补；某 AI 连续两轮被评差→只换该环节的席位；汇总者按采纳率轮换测试。

## 二、准入门槛

- **rules**：必须是真免费且可长期用（永久免费档 / 长期免费层）。一次性注册赠额不算主力，只能当备用。、必须有『按天或按周期重置』的免费额度——只给一次性新用户赠额、用完即止的，不进主力名单。、额度必须够用：单次额度太小（如每 2 小时约 10 条）判为『体验级』，直接排除。、通道限制：API 通道只留 豆包 + DeepSeek 两家；其余一律走『网页版』或『电脑端程序』接入（用户硬性要求）。、必须能稳定登录长期使用（不接受靠频繁换号、随时被封的）。、同一厂商同一模型只算一个席位——同源互审等于没审（见 crossVendorRule）。
- **quotaLevels**：充足:每日额度很大或近乎不限（如每天数百万 token / 文字对话不限次）→ 可当主力写手；够用:每日额度足以跑完一个环节的多轮对话 → 可当主力，长环节注意节流；偏紧:额度勉强够跑短环节 → 建议只用于审核/关键块，或减量使用；体验级:额度太小，只够试用 → 按规则排除，不进主力名单
