## 三、六要素（写作的统一审核框架）

写书阶段审核框架：正文/分布按 始・显・通・动・成・终 拆6段后，统一按本框架审核（替代逐环盲审打分）。sixAudit=true 时，每段在拼接前由 N-1 盲审官对照该段所属六要素审核标准打勾，并由 merge_app 在拼接后跑一次全章六要素红线校验（动≠成/成≠终/始≠显/硬钩不连续两章）。任一要素不达标或红线命中，回退到对应段补做，不进 章内节奏自检。

| 要素 | 含义 | 创作动作 | 关键词 |
|---|---|---|---|
| **始** | 主角状态、困局种子、既有局势 | 交代现状，埋欲望与缺陷 | 种子・现状・欲望 |
| **显** | 冲突登场，问题浮出水面，主角被迫上台 | 让矛盾显现，给主角一个“不得不” | 登场・触发・不得不 |
| **通** | 发展推进，受阻、积累、层层加码 | 连续动作，节节受阻节节进 | 推进・阻碍・积累 |
| **动** | 关键抉择、局势剧变、立场反转 | 主角主动跨一步，或信息揭露引发跃迁 | 抉择・剧变・反转 |
| **成** | 冲突阶段性兑现，目标达成或重创 | 兑现铺垫，给出结果 | 兑现・高潮・结果 |
| **终** | 代价显现、余韵、新钩子 | 结算代价，留钩子或物件特写 | 代价・余韵・钩子 |

### 3.1 每要素的审核要点与不合格表现

**始**
- 审核要点：
  - [ ] 清晰交代主角当前状态、处境、境界/心理基线。
  - [ ] 埋下本段/本章欲望与缺陷的种子（非直述，用环境/他人反应暗示，符合留白铁律#11）。
  - [ ] 既有局势/势力格局铺垫清楚，读者知道“现在在哪、水有多深”。
- 不合格表现：
  - ✗ 开头用天气、风景、回忆、设定切入（违反章首方式）。
  - ✗ 直接进冲突但读者不知主角处境，一头雾水。
  - ✗ 种子完全没埋，或埋得过于直白失去悬念。

**显**
- 审核要点：
  - [ ] 有具体冲突/问题在本段显现，矛盾破土。
  - [ ] 主角被推到台前，存在“不得不行动”的压力。
  - [ ] 触发点清晰（登场・触发・不得不）。
- 不合格表现：
  - ✗ 冲突迟迟不显，通篇铺垫无触发。
  - ✗ 主角被动，没有“不得不”的压力。
  - ✗ 显与始混淆（把显当始，缺种子期）。

**通**
- 审核要点：
  - [ ] 有连续的动作/事件推进，中段主体充实。
  - [ ] 节节受阻、节节进，有阻碍也有积累，张力不断。
  - [ ] 信息/冲突/情绪层层加码，不原地打转。
- 不合格表现：
  - ✗ 原地打转，同一冲突强度重复多段。
  - ✗ 只有推进没有阻碍（顺风顺水无张力）。
  - ✗ 推进过快无积累，读者没代入。

**动**
- 审核要点：
  - [ ] 有主角主动的关键抉择 OR 局势剧变/立场反转。
  - [ ] 是动作/抉择本身（非结果），为“成”铺垫。
  - [ ] 引发后续跃迁，推动剧情质跳。
- 不合格表现：
  - ✗ 动与成混淆（把结果当动作，缺兑现）。
  - ✗ 主角不主动，纯被动接受。
  - ✗ 无剧变/反转，平淡过渡无跃迁。

**成**
- 审核要点：
  - [ ] 本段给出阶段性结果（达成或重创）。
  - [ ] 是“动”带来的兑现，顺序在动之后。
  - [ ] 有高潮感/结果感，读者得到回报。
- 不合格表现：
  - ✗ 成与动混淆（先成后动，顺序颠倒）。
  - ✗ 成与终混淆（只有达成无代价余韵 → 断头路）。
  - ✗ 无兑现，冲突悬空未落地。

**终**
- 审核要点：
  - [ ] 显化本段/本章代价（非纯爽）。
  - [ ] 有余韵/物件特写/情绪沉淀。
  - [ ] 留断章钩（且不与上章同类型硬钩连续）。
- 不合格表现：
  - ✗ 无终之成（纯爽无代价，断头路）。
  - ✗ 章末总结、抒情、无钩。
  - ✗ 硬钩连续两章同类型。

### 3.2 单章节奏

```
始(1-2段·承上章钩) → 显(1-2段·冲突上台·不得不) → 通(中段主体·节节受阻节节进)
→ 动(1段·关键转折·抉择/剧变/反转) → 成(1段·阶段兑现·高潮结果) → 终(章末·代价/余韵 + 断章钩)
```

### 3.3 自检红线（硬规则）

| 红线 | 规则 |
|---|---|
| **动≠成** | 动是动作/抉择，成是这个动作带来的结果兑现——先动后成，顺序不可颠倒。 |
| **成≠终** | 成是目标达成，终是达成后的代价与余韵——无终之成=断头路（纯爽无代价）。 |
| **始≠显** | 始是平静的种子，显是种子破土/冲突上台的那一下，要给出主角不得不行动的压力。 |
| **硬钩不连续两章** | 断章钩不能连续两章同类型硬钩，避免读者疲劳。 |

## 四、正文终审（写作出口）

- **program**：写作
- **gate**：正文终审
- **position**：写作程序出口（润色开始前）
- **executesAt**：章内节奏自检
- **voters**：全员 N
- **passRule**：过半通过
- **checks**：六要素 始显通动成终 齐全且顺序对、四条红线未命中（动≠成/成≠终/始≠显/硬钩不连续两章）、章纲对齐无跑偏、单章字数与断章钩达标
- **platformChecks**：单章 1500—2300 字（日更 4000 拆两章）、开篇 300 字内出冲突；前三章 = 第1章遇麻烦 / 第2章得转机 / 第3章开始反击、每 500—800 字一个转折点；章末钩不与上一章同类型、爽点即时兑现、无憋屈累积；短段落短句、段落长度适配手机端、每章 ≤2 个场景、≤1 个新概念（设定按需投放）
- **onPass**：本章正文定稿 → 进 润色
- **onFail**：回退对应六要素段重拼
- **onTie**：交叉提意见 + 综合改稿 + 再投（上限 2 轮，仍平票则人工裁决）
