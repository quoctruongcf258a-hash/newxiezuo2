## 二、八方向审核标准（规划的统一验收框架）



规划按 23 环执行，但**验收不逐环打分，统一按下面八大方向的标准**。每个方向所辖环节全部汇总后触发一次方向级审计：逐条对照 `审核标准` 打勾，并对照 `不合格表现` 查反模式；出现待改/反模式命中 → 回退对应执行环补做。

### 定位与约束　`定位与约束`
- 所辖环节：规划前约束、类型平台读者卖点
- 执行延伸：发布与合规、书名设计、标签选择、封面设计规划
- 要回答：
  - 写给谁？
  - 写什么类型？
  - 发哪里？
  - 写多少？
  - 写多久？
  - 每天投入多少？
- 审核标准（逐条打勾）：
  - [ ] 能 10 秒说清类型、子类型、读者、卖点。
  - [ ] 知道目标平台、签约意向、更新要求。
  - [ ] 知道总字数、总章数、每章字数、卷数。
  - [ ] 知道每天投入时间、每周天数、预计周期。
  - [ ] 有竞品分析和差异点。
  - [ ] 有雷点避让清单。
  - [ ] [包装·补] 书名能 10 秒说清品类、易记易搜、无同名撞车。
  - [ ] [包装·补] 标签全部取自平台实有标签池，3—5 个，不虚标不堆砌。
  - [ ] [包装·补] 封面 brief 完整：缩略图可读、无侵权素材与字体、无违规元素。
- 不合格表现：
  - ✗ 类型模糊，既像言情又像玄幻。
  - ✗ 写给所有人，等于写给没人。
  - ✗ 目标虚高，三天后崩盘。
  - ✗ [包装·补] 包装与内容调性不一致（甜美封面配暗黑文 / 标签虚标错放）。

### 故事核心　`故事核心`
- 所辖环节：一句话故事、简介与主题
- 执行延伸：上架简介
- 要回答：
  - 这本书讲什么？
  - 主角想要什么？
  - 阻力是什么？
  - 失败会怎样？
  - 主题是什么？
  - 核心问题是什么？
  - 价值冲突是什么？
- 审核标准（逐条打勾）：
  - [ ] 一句话故事包含主角、身份、欲望、阻力、代价。
  - [ ] 读一遍能让人想问“然后呢？”
  - [ ] 简介 150—300 字，包含常态、变故、行动、悬念。
  - [ ] 简介能直接当平台简介。
  - [ ] 有主题、核心问题、价值冲突。
  - [ ] 主题能指导剧情取舍。
  - [ ] [包装·补] 上架简介首句即钩子，3 秒看完想点开，可直接粘贴平台简介栏。
  - [ ] [包装·补] 简介卖点词真实存在于正文，不虚标、不剧透结局。
- 不合格表现：
  - ✗ 只有设定，没有欲望和代价。
  - ✗ 简介写成世界观说明书。
  - ✗ 主题空泛，无法指导写作。
  - ✗ [包装·补] 上架简介首句平铺不抓人，或卖点词与正文不符。

### 人物系统　`人物系统`
- 所辖环节：主角设计、核心冲突与反派、核心配角与人物关系
- 要回答：
  - 主角是谁？
  - 他想要什么？
  - 他怕什么？
  - 他有什么缺陷？
  - 他如何变化？
  - 反派是谁？
  - 反派为什么合理？
  - 配角承担什么功能？
- 审核标准（逐条打勾）：
  - [ ] 主角有基础信息、外貌、性格。
  - [ ] 主角有表层欲望、深层欲望、恐惧、创伤、秘密。
  - [ ] 主角有能力、能力代价、弱点、口癖。
  - [ ] 主角有初始状态、终局状态、五卷成长弧光。
  - [ ] 主角主动，不是被动挨打。
  - [ ] 主角有缺点，不是完美无缺。
  - [ ] 反派有目标、动机、镜像点、资源、弱点、底线、结局。
  - [ ] 反派不是弱智，不是纯恶，有自己的逻辑。
  - [ ] 有 5—10 个核心配角。
  - [ ] 每个配角有目标、恐惧、秘密、作用、弧光、结局。
  - [ ] 有完整人物关系图。
  - [ ] 每个配角不是工具人。
- 不合格表现：
  - ✗ 主角完美无缺、天赋逆天、没有代价。
  - ✗ 反派只会派小兵送经验。
  - ✗ 配角功能重复，名字难记。

### 世界系统　`世界系统`
- 所辖环节：世界规则最小集
- 要回答：
  - 世界怎么运转？
  - 力量体系是什么？
  - 代价是什么？
  - 限制是什么？
  - 势力有哪些？
  - 社会结构如何？
  - 历史大事有哪些？
- 审核标准（逐条打勾）：
  - [ ] 有主要地图、3—5 个势力。
  - [ ] 有社会结构、经济、文化禁忌。
  - [ ] 有力量体系：等级、能力、代价、限制、获取、禁忌、克制。
  - [ ] 力量必须有代价。
  - [ ] 力量必须有极限。
  - [ ] 设定必须能制造冲突。
  - [ ] 读者能理解规则。
  - [ ] 有影响现在的 3 件历史大事。
  - [ ] 有日常细节：货币、饮食、交通、称呼。
- 不合格表现：
  - ✗ 先写十万字世界观，结果正文卡住。
  - ✗ 力量体系无代价，主角无敌。
  - ✗ 设定与剧情无关。

### 结构与结局　`结构与结局`
- 所辖环节：结局与终局、分卷结构、情绪规划、节奏规划
- 要回答：
  - 最后是什么画面？
  - 主角最终变成什么样？
  - 世界发生了什么变化？
  - 代价是什么？
  - 分几卷？
  - 每卷目标是什么？
  - 每卷高潮在哪？
  - 情绪怎么走？
  - 节奏怎么控？
- 审核标准（逐条打勾）：
  - [ ] 知道终局画面、主角最终状态、世界变化、最大代价。
  - [ ] 能用 300 字讲完结局。
  - [ ] 结局有代价、有变化，不是只有“打败反派”。
  - [ ] 分了 4—5 卷，每卷 20—25 万字。
  - [ ] 每卷有独立目标、主要冲突、新人物、新地图。
  - [ ] 每卷有高潮、结尾钩子、伏笔埋收、主角变化。
  - [ ] 每卷结尾都有大转折。
  - [ ] 有全书情绪主基调。
  - [ ] 有每卷情绪曲线：压抑、释放、爽点、痛点、燃点、泪点。
  - [ ] 有信息释放节奏、冲突升级节奏、高潮间隔、张弛比例、钩子密度。
  - [ ] 能说清每卷哪里快、哪里慢、哪里爆。
- 不合格表现：
  - ✗ 只有“打败反派”，没有代价和变化。
  - ✗ 每卷重复“升级—打怪—升级”。
  - ✗ 一直爽、一直虐、情绪无变化。
  - ✗ 全程高能，或中段拖沓。

### 开局细化　`开局细化`
- 所辖环节：前30章章纲
- 执行延伸：开篇黄金三章爆破
- 要回答：
  - 第 1 章写什么？
  - 黄金三章怎么抓人？
  - 前 10 章节奏如何？
  - 第 11—30 章方向是什么？
- 审核标准（逐条打勾）：
  - [ ] 第 1 章有钩子、主角、冲突、悬念、结尾钩子。
  - [ ] 第 2 章有冲突升级、规则展示、选择、钩子。
  - [ ] 第 3 章有小高潮、明确目标、大钩子。
  - [ ] 前 10 章每章有 200—300 字细纲。
  - [ ] 第 11—30 章每章有 100 字中纲。
  - [ ] 章纲包含：章号、标题、视角、地点、时间、核心事件、冲突、情绪、爽点/痛点、伏笔、结尾钩子。
  - [ ] 能直接照着章纲进入正文阶段。
  - [ ] 第一章没有写风景、设定、梦。
- 不合格表现：
  - ✗ 第一章写风景、写设定、写梦。
  - ✗ 前 30 章没有细纲，写到哪算哪。
  - ✗ 黄金三章没有钩子。

### 追踪与备份　`追踪与备份`
- 所辖环节：伏笔时间线关系表、文档与备份
- 要回答：
  - 伏笔埋了哪些？收了哪些？
  - 时间线有没有乱？
  - 人物关系怎么变？
  - 稿子丢不了吗？
- 审核标准（逐条打勾）：
  - [ ] 有伏笔表：编号、埋设章节、内容、计划回收、实际回收、状态。
  - [ ] 有时间线：故事日期、主角年龄、大事件、涉及人物、结果。
  - [ ] 有人物关系图：爱、恨、欠、利用、背叛。
  - [ ] 有章节状态表：章号、标题、状态、字数、修订、发布。
  - [ ] 有文件夹结构：总纲、世界观、人物表、时间线、卷纲、章纲、伏笔追踪、素材库、正文、修订记录、发布计划。
  - [ ] 有命名规则：第001章_标题_v01。
  - [ ] 有备份方案：本地、云盘、移动硬盘、每日自动备份。
  - [ ] 丢一个设备，稿子还在。
- 不合格表现：
  - ✗ 前面埋的伏笔后面忘了。
  - ✗ 时间线前后矛盾。
  - ✗ 只存一个地方，电脑坏了全没了。

### 规划验收　`规划验收`
- 所辖环节：规划验收
- 要回答：
  - 所有规划都完成了吗？
  - 规划之间有矛盾吗？
  - 能进入正文阶段了吗？
- 审核标准（逐条打勾）：
  - [ ] 所有规划产出物已齐备。
  - [ ] 所有规划之间没有矛盾。
  - [ ] 所有规划都指向冲突和人物变化。
  - [ ] 依赖顺序合理：总纲→人物→世界→结局→分卷→情绪→节奏→章纲→追踪→验收。
  - [ ] 规划到 70%，可以进入正文阶段。
  - [ ] 不会因为规划不足而卡文。
  - [ ] 不会因为规划过度而瘫痪。
- 不合格表现：
  - ✗ 规划瘫痪，永远在规划。
  - ✗ 规划之间互相矛盾。
  - ✗ 规划太粗，写的时候全靠现编。

## 三、章纲终审（规划出口）

- **program**：规划
- **gate**：章纲终审
- **position**：规划程序出口（写作开始前）
- **executesAt**：规划验收
- **voters**：全员 N
- **passRule**：过半通过
- **checks**：八方向审核标准全过（auditDirections 72 条）、前30章章纲齐备且含六要素阶段字段、设定/人物/伏笔表无矛盾、能直接进正文
- **platformChecks**：番茄立项核查：类型落在番茄主力品类或 2026 趋势赛道内、书名备足 ≥5 个（20—50 万字与 100 万字书测各需提交 5 个）、书名含品类搜索词、2—6 字、无生僻字与特殊符号；分类标签全部取自番茄后台实有标签池、简介前三行完成钩子展示、无推广导流信息；封面含书名+作者名、600×800、无外站水印、分卷结构与番茄生命周期对齐（0-2万 / 2-8万 / 8-10万验证期 / 10万+首秀 / 20-50万书测 / 100万书测）
- **onPass**：锁定章纲 → 进 写作
- **onFail**：回退对应规划环补做
- **onTie**：交叉提意见 + 综合改稿 + 再投（上限 2 轮，仍平票则人工裁决）
