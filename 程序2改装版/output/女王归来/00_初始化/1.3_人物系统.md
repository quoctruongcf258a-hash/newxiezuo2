# 1.3 人物系统

**主角档案**
- **姓名**：奥古斯都·伊芙琳（Evelyn）
- **身份**：曾被背叛陨落的魔法女皇 / 现今重归王座的复仇者。
- **性格**：冷傲、霸道、高冷、御姐、女强人、冷静、偏执、傲慢。
- **动机**：清洗叛徒，摧毁旧世界，用魔法与契约建立只属于她的绝对统治。
- **弧光**：无需成长弧光，全程满级心态。她要做的不是改变自己，而是改变这个世界，让世界适应她的偏执与傲慢。

**核心配角（6人）**
本剧无CP，所有配角均为女主的从属、工具或狂热追随者。
1. **神秘残魂（师父型）**：上古时期的禁忌魔法师残魂。初期试图教导女主，后期被女主的霸道折服，彻底沦为提供远古知识的“随身智囊”。
2. **深渊魔龙（宠物型）**：传说中的灭世魔兽。平时可以化作袖珍形态，一旦解开契约限制，便是摧城拔寨的大杀器，只对女主一人温顺。
3. **利刃骑士**：女主最忠诚的利剑。沉默寡言，绝对服从女主的任何杀戮指令。
4. **腹黑情报官**：替女主处理黑暗面的脏活累活。极度敬畏女主的手段。
5. **狂战首领**：粗犷好战，被女主在力量上绝对碾压后宣誓效忠，战场上的先锋。
6. **天才魔法少女（迷妹）**：大陆百年难遇的天才，将女主视为唯一的神明，狂热崇拜，女主势力的狂热布道者。

**反派阵营**
- **背叛的旧部**：窃取了女主部分力量和地位的旧贵族与领主，在女主归来时恐惧战栗。
- **圣光教皇**：虚伪的秩序维护者，企图用宗教的名义审判女主。
- **虚伪神明**：大陆幕后的真正控制者，最终被女主从神座上拽下。

**关系网原则**
主从分明。女主位于金字塔最顶端，所有角色要么臣服于她的契约，要么死于她的魔法。绝不存在与女主地位对等的浪漫关系。
