# 怎么用（每天 4 步）

> 这套流水线跑在**你自己的 Windows 电脑上**，用 Windows-Use 操控你打开的 AI 窗口。
> 它的设计前提是：**你每天能用的 AI 不一定一样**，所以每次开跑前先登记"今天开了哪些"。

---

## 一、每天的操作流程

### 第 1 步 · 打开你打算用的 AI

- **网页版**：在浏览器（推荐 EDGE）里逐个打开并**登录好**，停在能提问的页面。
- **桌面端**：把程序（如 Antigravity、豆包电脑版）**手动启动好**，确认能正常提问。

> 不用全部打开。3—5 个就够跑（1 个写、其余审）。开局建议用「稳健五人组」。

### 第 2 步 · 登记今日阵容（双击 `run_gui.bat`）

打开「今日阵容」页：

1. **勾选**今天打开的 AI；
2. **核对形态**：网页选 `web`，桌面程序选 `desktop`；
3. **核对地址**：网页填网址；桌面端点「浏览」选 **exe 路径**；
4. **选拼接者**（汇总者）——它负责把各版本按段落择优拼成一稿；可以是参战成员，也可以是今天打开的专职拼接者（如元宝）；
5. 点「保存今日阵容」→ 写入 `today.json`。

> 也可以直接告诉我「今天开了豆包、Kimi、Gemini 网页，还有 Antigravity 桌面端」，我照这句把 `today.json` 写出来。

### 第 3 步 · 先校验，再试运行

切到「运行设置」页：

| 动作 | 作用 | 什么时候用 |
|---|---|---|
| **校验阵容** | 查人数是否 ≥2、拼接者是否在列、有没有跨厂告警 | 每次开跑前 |
| **探测可用** | 逐个打开 AI，查是否被登录页/额度提示挡住 | 换了一批 AI 时 |
| **跑规划 / 写作 / 润色 / 质检** | 正式干活 | 见下 |
| **手动复检** | 强制跑一次连贯性复检 | 想临时抽查时 |

**第一次务必先「试运行」**——窗口里会打印全部将派发的任务，确认流程对了再「正式运行」。

### 第 4 步 · 正式运行

正式运行期间**不要碰鼠标键盘**（GUI 代理正在控制它们），直到窗口跑完。

## 二、四个程序分别怎么跑

| 程序 | 动作 | 章号 | 产出 | 出口闸 |
|---|---|---|---|---|
| 一 · 规划 | 跑规划 | 可留空 | 章纲 + 上架包装 | 章纲终审 |
| 二 · 写作 | 跑写作 | 如 0057 | 本章正文 | 正文终审 |
| 三 · 润色 | 跑润色 | 如 0057 | 润色定稿 | 润色终审 |
| 四 · 质检 | 跑质检 | 如 0057 | 入库定稿 + 质检报告 | 成书检验 |

- **规划只跑一次**——章纲锁定后就进入章节循环，不再回头改大纲。
- **写作 / 润色 / 质检是逐章循环**：一章一章走完，再进下一章。
- **每 10 章自动追加一次连贯性复检**（第 10/20/30…章入库后自动触发，不用手动）。
- 想只跑某个环节：在「只跑某一环」下拉里选（例如只跑「正文」）。

**质检不合格时的回退**（程序自动按类型分流）：

```
表达/文风类 → 回 润色       内容/结构类 → 回 写作       设定/世界观类 → 回 规划
```

## 二·五、赛马记分榜（谁好谁差，用数据说话）

每个程序的**终审闸**里，投票官在投票之外还会给本次参战的 AI **逐个打分（1—10，附依据）**；拼接者每拼一块会留下**采纳标记**。这些数据由记分榜自动累计：

| 记什么 | 干什么用 |
|---|---|
| **终审打分** | 谁的产出质量高、返工少、不反复踩坑 |
| **拼接采纳** | 谁写的段落最常被采纳 → 生成「**环节 × AI 最佳对照表**」（以后就知道用谁写哪个环节） |
| **垫底淘汰** | 同一程序**连续 3 次垫底且均分 < 6.0** → 自动淘汰，以后默认不用它（今日阵容里强行勾选会告警） |
| **冠亚季军** | 跑满 2 轮后有资格，按累计均分 + 采纳次数排名 |

**怎么查**（跑完任意程序后随时看）：

```bat
python orchestrator.py --board          REM 全场总榜 + 冠亚季军 + 环节对照表
python orchestrator.py --board 写作     REM 只看写作程序
```

跑完一个程序的出口闸时，控制台也会自动打印「📊 记分榜（本轮）」和冠亚季军。

**淘汰了能反悔吗？** 能：

```bat
python scoreboard.py restore tongyi     REM 解除淘汰，重新获得参战资格
python scoreboard.py reset              REM 清空整张记分榜（重新开始统计）
```

> 打分是**终审官集体评的**（每位投票官都打，去掉自评取均值），不是某一个 AI 说了算；淘汰线与连败次数在 `apps.json` 的 `scoreboard.elimination` 里可调。

## 三、三个配置文件的分工

| 文件 | 管什么 | 什么时候改 |
|---|---|---|
| `today.json` | **今日阵容**：今天打开了哪些 AI、什么形态、谁是拼接者 | 每天都在变（GUI 自动写） |
| `roster.json` | **候选池**（长期）：有哪些可选 AI、默认网址、预设阵容、四层选人覆盖 | 名单变动时改 |
| `apps.json` | **流程与标准**（长期）：四程序、环节链、审核标准、番茄约束、投票规则 | 想改流程/标准时改 |

> 主副本在 `C:\mai\multi-ai-pipeline\windows-use\`。
> `G:\迅雷下载\novel_tools\万象宇宙\newskill\` 下的是**只读镜像**，由导出脚本生成；改配置请改主副本再重跑导出。

## 四、产出在哪

```
multi-ai-pipeline/work/
├── 规划/
│   ├── 主角设计/versions/   ← 各 AI 的版本
│   │            reviews/    ← 盲审 JSON
│   │            merged/     ← 逐块择优结果
│   │            phase_candidate.md   ← 本环节候选稿
│   └── 章纲/phase_candidate.md       ← 锁定的章纲
├── 写作/ch0057/
│   ├── 章前对齐卡/  分布/  正文/  章内节奏自检/
│   └── _gate/round1/vote__*.json     ← 终审投票
├── 润色/ch0057/润色/
├── 质检/ch0057/
│   ├── 逻辑设定一致/ 平台合规/ 爽点节奏/ 文风格式回查/ 质检汇总/
│   ├── 上架前低级错误检查/
│   └── _recheck/recheck_report.md    ← 每 10 章复检报告
└── library/第0057章.md               ← 最终入库成品

multi-ai-pipeline/windows-use/work/scoreboard.json   ← 赛马记分榜（打分/采纳/淘汰/排名）
```

**每 10 章复检报告**里的每条问题都是「问题定位卡」四件套：
① 位置（到段）② 命中标准条目 ③ 正文关键句 + 检索词 ④ 修改建议。
作者逐张三选一：**改 / 不改 / 延后**。

## 五、一次性安装

```
双击 install_fast.bat
```

它会用本地 Python 3.13.12 建 `.venv` 并装 `windows-use`。

- **图形界面**（`run_gui.bat`）需要带 tkinter 的 Python——脚本会自动挑选；
  `.venv` 没有 tkinter 也没关系，界面会改用系统 Python，流水线仍用 `.venv`。
- **命令行兜底**：`run.bat`（菜单式，无图形环境时用）。

## 六、常见问题

**Q：某个 AI 一直没反应 / 卡住？**
A：多半是登录掉了、出现验证码、或额度用完。用「探测可用」先查一遍；把不可用的从今日阵容里取消勾选再跑。

**Q：人数不够怎么办？**
A：网格写作至少 2 人（1 写 1 审）。校验时若报"只有 1 名参战"，再打开一个 AI 登记进来。

**Q：拼接者能换吗？**
A：能。在「今日阵容」页改选即可。想知道谁拼得好——看各环节被终审采纳的比例，采纳率高的固定下来。

**Q：跑到一半想停？**
A：直接在控制台按 `Ctrl+C`，或关掉那个窗口。已落盘的版本不会丢（都在 `work/` 里）。

**Q：审核是隔离的吗？**
A：是。每个 AI 都新开独立会话，盲审官看不到其它版本、也看不到历史对话。运行时**不要手动**去某个对话里插话或翻记录。

**Q：番茄合规怎么保证？**
A：配置里**当前默认 `complianceMode = aiDirect`**（2026-10-02 你裁定切过来的）——多 AI 网格**直出正文**，你按需参与关注与审核（旁听环节审核与终审投票、必要时一票否决），主要目的是测试 AI 直出写作的实际效果；你不在场的轮次流程照常自动跑，靠既有闸口（分块大家审核、终审投票过半、质检 AI 合规闸、去 AI 味专项）把关。

⚠️ **风险须知**：番茄 2026 年严查整章 AI 生成——机器文本比例高会在 8 万字评估环节被驳回（烧掉仅有的 3 次签约名额），长篇被抽检到文风僵硬段会切断流量，严重时追回稿费。所以质检的「AI 使用合规质检」+ 每章入库前的机器文本自查**不能省**。

想切回合规模式：把 `apps.json` 的 `complianceMode.default` 改成 `"aiAssist"`——写作程序改为出**写作蓝图**（骨架/走位/细节候选/对话备选），正文由你亲手写或对 AI 段落改写 ≥70%，过签最稳。无论哪种模式，「AI 使用合规质检」都是一级必过项。
