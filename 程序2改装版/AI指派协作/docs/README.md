# 多 AI 协作写作流水线（番茄小说定制 · 四程序版）

> 编排总线：让多个**外部免费 AI**（网页版 / 桌面端程序）按同一套规则协作，完成从「一个思路」到「上架正文」的全流程。
> 你只负责**开软件 + 点选今日阵容**，其余由 Windows-Use 驱动各 AI 窗口自动完成。

---

## 一分钟看懂

```
程序零 · 阵容    →  每次开跑前登记「今天开了哪些 AI」（GUI 点选）
     ↓
程序一 · 规划    →  23 环  →  章纲终审  →  锁定章纲（只走一次，永不回头）
     ↓
程序二 · 写作    →  每章 4 环  →  正文终审  →  逐章循环
     ↓
程序三 · 润色    →  28 项标准  →  润色终审
     ↓
程序四 · 质检    →  9 环  →  成书检验  →  上架前低级错误检查  →  入库
     ↓
            每 10 章 → 连贯性综合复检（全员参与，问题带优先级，作者裁定）
```

每个程序一道终审闸，**全员投票过半通过**；平票走「交叉提意见 + 综合改稿」再投（上限 2 轮）。

---

## 三条设计铁律

1. **AI 一律走外部**：写作 / 盲审 / 拼接 / 投票全部用外部 AI 软件（豆包、DeepSeek、Kimi、通义、元宝、Gemini、Antigravity…）。本目录**不**调用 WorkBuddy 内部多 Agent。
2. **全员既是写手也是盲审官**：每个环节里，N 个成员中一人（或多人分块）产出、其余 N-1 人隔离盲审、指定一名拼接者按块择优。角色轮转，无固定分工。
3. **盲审必须跨厂**：同厂商不同型号不算独立（同源模型有同一盲区）。评审一律新建独立对话，互不可见。

## 单权威副本纪律

- **主副本**：`C:\mai\multi-ai-pipeline\windows-use\{apps,roster}.json` — 改这里。
- **只读镜像**：`G:\迅雷下载\novel_tools\万象宇宙\newskill\协同层\配置\` — 自动生成，别手改。
- 改完主副本后重跑一次同步：
  ```bash
  python scripts/export_newskill.py
  ```
  该脚本把全部流程/标准文档从配置自动生成到 newskill（含 `--check` 只校验模式），保证分发内容永不漂移。
