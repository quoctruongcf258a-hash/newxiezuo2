## 八、本项目新增的「三大程序」代码层（⚠ 原 v0.8 清单未覆盖，接手 AI 必读）

当前工作区在 v0.8 基础上，由用户授权新增了三个并列程序（竞赛 / 协同 / 蒸馏），并抽出一层共享核心 `core/`。这部分是**全新代码**，原工具清单未列入。注意以下边界：

### 新增目录（归属各程序主管，受保护策略）
- `core/`  ★ 三程序共享层（不归属 v0.8 任何既有模块）
  - `delivery.py`（dispatch / batch_dispatch / mix_available，薄封装 mix_send，自带 dry_run 模拟）
  - `blind_review.py`（anonymize / pick_judges 跨厂裁判 / schedule_reviews）
  - `scoreboard.py`（AI×维度矩阵 / 排行 / 冠亚季 / 末位淘汰）
  - `visualize.py`（heatmap / radar / export_html，matplotlib Agg）
  - `cdp_reply.py`（只读抓取 AI 网页回复，best-effort）
  - 死约束：**core/ 接口已冻结，任何程序改 core 接口须经主管→总主管确认**，不得擅改签名。
- `compete/`  ★ 程序一·AI 写作擂台（竞赛）
  - 入口 `launcher_compete.py`（双击启动 PySide6 窗口，自动注入 core/、compete/ 到 path）
  - `compete_core.py`（CompeteEngine 状态机）、`config_loader.py`、`judges.py`、`export.py`、`cli_dryrun.py`、`ui_main.py`、`requirements.txt`
  - 跑法：`windows-use\.venv\Scripts\python.exe compete\launcher_compete.py`（本机装依赖后）
- `distill/`  ★ 程序三·AI 蒸馏（扒取番茄爆款 + 拆解）
  - `scraper.py`（FanqieScraper：CDP 只读扒取 + 本地 TXT 桩 + 合规提示）
  - `engine.py`（封装 NEWSKILL 蒸馏引擎 + 生成「可复用套路清单.md」）
  - `report.py`（自包含 HTML 可视化）、`cli.py`、`__init__.py`、`README.md`
  - 跑法：`python -m distill.cli distill -f <本地txt> -n 书名 -g 爆款 --no-native`；`python -m distill.cli report -n 书名`
  - 死约束：**严禁改 NEWSKILL 引擎源码、mix_send.py、ai_apps.json、core 既有文件**。
- `ui/` 下程序二·协同写作扩展（★ 在 v0.8 既有 ui/ 内新增，不破坏既有文件）
  - 新增 `stage_board.py`（可编辑环节表 LINKS）、`assign_panel.py`（环节→AI 指派面板）、`collab_auto.py`（串跑）
  - `pipeline_runner.py` 已加 `action="assigned"` 分支（保留原 broadcast/batch/merge/final 不动）
  - 待补 `collab_app.py`（协同主窗口 + 入口）
  - 协同产物独立目录 `work/collab/`（不混用程序一赛马目录）

### 与 v0.8 的关系
- 三大程序**复用** v0.8 的 `windows-use\mix_send.py`（投递）、`config\ai_apps.json`（选手配置）、`ui\players.py`（启动/关闭 AI 窗口），**不重写**。
- 程序二通过 `core\delivery.dispatch` 发任务（自带 dry_run + best-effort 回抓），不直接调 mix_send。
- 新增 AI 仍按原流程（UI「➕ 添加选手」或改 `ai_apps.json`）；三大程序用 `config_loader` 读 `ai_apps.json` 但**不改**它。

### 给接手 AI 的额外提醒（三大程序）
- 跑三大程序一律用 `windows-use\.venv\Scripts\python.exe`（系统 Python 3.14 不用）。
- 程序一 GUI 依赖 PySide6 / matplotlib：本机若 venv 缺，先 `pip install -r compete\requirements.txt`（用 venv 的 pip）。
- 程序三 `scraper` 真实扒取依赖 `websocket-client`（windows-use/.venv 应有）；本地桩模式不需要。
- 不要动 `core/` 既有接口、`mix_send.py`、`ai_apps.json`（除非明确要做 v0.8 维护）；三大程序的源码改动请通过对应程序主管 / 总主管协调。
