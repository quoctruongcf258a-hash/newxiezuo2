## 三、已修掉的问题（这就是之前"全部打不开"的原因）

### 1. bat 编码错误 —— 最直接的元凶
启动器原本是 **UTF-8 编码**，而 Windows cmd 按 **GBK(ANSI)** 解析 bat。中文行被解成乱码，**破坏了 bat 语法**，双击后命令根本没执行到 Python。

- 修复：全部改为 **GBK 编码 + CRLF 换行**（已校验：乱码行 = 0）

### 2. F 副本运行环境残缺 —— 已修复完成
第一次搬家用 `cp` 复制 847M 的 `.venv`，中途大量 `Permission denied` 中断，只得到 184/413 个包的残废环境 → 主界面 import 失败闪退。

- 修复：删除残缺环境，改用 Windows 原生 **robocopy** 重建 → **已完成**：35306 文件、0 失败、857M、413/413 包
- 实测：用 F 副本独立 venv 启动主界面，**进程存活 12 秒、零报错**（不再依赖原盘）

### 3. 登记台（tkinter）在 venv 里根本不可用
实测 venv 的 Python **没有 tkinter**，登记台启动即报"tkinter 不可用"。这是原盘环境本身的限制，不是搬家造成。

- 修复：登记台改用**系统 Python 3.14**（实测带 tkinter 8.6，已验证窗口能弹出）

### 4. 原盘 `windows-use/run.bat` 本身是坏的
它调用 `orchestrator.py`，但那个脚本实际在 `_scratch/` 子目录，根目录下并没有 → 点了会报找不到文件。

- 修复：命令行菜单重建，正确 `cd` 到 `_scratch` 后再调用

## 六点五、37 环「真正嵌入」执行层（不只是挂配置）

> **重要**：把 37 环写进 `rules/phases.json` 只是**配置层接入**。
> 程序2 的执行引擎 `app/phase_runner.py` 原本**完全不读 `mode` 字段**，
> 而且 37 环缺 prompt 模板会被直接跳过。以下三处缺口已全部修补。

### 缺口 1：mode 不生效 → 已加模式分派

`run_subphase` 原本是写死的「执行 → 审核 → PASS/FAIL → 调整」串行，
所有环跑同一套流程，`mesh/human/lock` 只是标注、不产生任何行为差异。

已给 `phase_runner.py` 增加模式分派（改前备份 `phase_runner.py.bak_embed`）：

| mode | 执行策略 | 产物 |
|---|---|---|
| `mesh`（28 环） | **N 写手各写一份 → 匿名化 → 跨厂裁判盲审 → 汇总者择优融合** | `draft_1..N.md`、`_盲审稿.md`、`review_1..M.md`、`final.md` |
| `human`（6 环） | AI 出候选 → 写 `pending.json` **停住等人拍板** | `candidate.md`、`pending.json` |
| `lock`（2 环） | AI 审计 → 写 `audit.md` → **等人锁定** | `audit.md`、`locked.json` |
| 无 mode（旧环） | 保持原三角色串行（向后兼容） | `output.md`/`review.md`/`final.md` |

### 缺口 2：缺 45 个 prompt 模板 → 已补齐

`run_subphase` 遇模板缺失即 `return None` 跳过。新接入的 37 环名
（`P01_规划前约束`、`W1_章前对齐卡`、`Q1_逻辑设定一致`…）在 `prompts/` 下
原本没有对应 `.md`（只有旧的 `1-1_定位与卖点` 等命名）——**不补的话一环都跑不了**。

已生成 **37 个专属模板**（内容取自设计源 desc + 该环 audit 标准），
并为每个阶段补 `_通用.md` 兜底；引擎也改为「无专属模板时回退 `_通用.md`」而非直接跳过。
复查结果：**仍缺模板或无兜底的环 = 0**。

### 缺口 3：明细无具体写手 → 已补跨厂指派

`assignments.json` 的明细原本只有 `mode/审核独立/audit`，没有写手，
"跨厂独立"只落在环节级兜底（如 `规划AI(轮转写手)`），没精确到环，赛马无从执行。

已为每环补：

| 角色 | 人选 | 厂商 |
|---|---|---|
| `writers`（5 写手） | 豆包 / 通义千问 / DeepSeek / Kimi / 腾讯元宝 | 5 家不同 |
| `judges`（3 裁判） | 智谱清言 / 文心一言 / 讯飞星火 | **与写手不同厂商**（跨厂铁律） |
| `merger`（汇总者） | 豆包 | — |
