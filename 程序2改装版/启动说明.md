## 一、原 UI 入口（桌面程序，无需新做）

程序2 自带两套图形界面，**都是桌面窗口程序**，不是网页：

| 界面 | 入口 | 技术 | 用途 |
|---|---|---|---|
| **主协同界面** | `app/collab_app.py` | PySide6 (Qt) | 六阶段流水线可视化操作台；阶段1「指派」直接读 `rules/assignments.json`（已改成 23 环 + 跨厂独立审核） |
| **今日阵容登记台** | `windows-use/_scratch/run_gui.bat`（双击） | tkinter | 勾选今天打开的 AI、选动作、试运行/正式运行；驱动 `orchestrator.py` |

### 本地启动方式（在你**有显示器的 Windows 机器**上）

**方式 A — 主界面（推荐先试）**
1. 安装依赖：`pip install PySide6`（或用原盘已装好的 `.venv` 拷过来）
2. 命令行进入本目录，运行：`python app/collab_app.py`
3. 界面出现后，进入「阶段1 指派」即可看到 **23 个规划细环**，分别指派执行/审核/调整者

**方式 B — 登记台（驱动真实赛马引擎）**
1. 需 Windows 官方 Python 且安装时勾选了「tcl/tk and IDLE」（自带 tkinter）
2. 双击 `windows-use/_scratch/run_gui.bat`
3. 勾选今天打开的 AI → 保存今日阵容 → 运行设置选「跑规划」→ 先「试运行(dry)」看任务清单 → 无误再「正式运行」

> ⚠️ 正式运行会**真实操控你电脑上的 AI 窗口**，运行期间请勿碰鼠标键盘。

## 二、23 环集成点（本次改装的核心）

- `rules/phases.json` 的 `01_规划`：**已由 7 粗环 → 23 细环**（P01…P23，对应第一版赛马机制的规划粒度）。
- `rules/assignments.json` 的 `01_规划`：移除原「执行=审核=调整=同一 AI」的自审问题，改为 23 环各自的**跨厂独立**指派（16 mesh / 6 human / 1 lock）。
- `windows-use/apps.json`（及 `_scratch/apps.json`）：`phases` 含 23 规划环，被 `orchestrator.py` 直接消费。
- `windows-use/_scratch/orchestrator.py`：`--program 规划` 即跑这 23 环，支持 `--dry-run`（纯模拟，不碰窗口）。
