# 写作硬指标速查（每次产出与盲审都带此件）

> 这些是**写作时的自检线**，用于约束笔头。它们不是评估打分项——
> 评估时不因分章、分段、标点方向等排版问题扣分（那条规则另见评估规范）。
> 若本节与【平台硬约束（番茄）】冲突，取**更严的一边**。

## 一、禁用句式（红线，最高优先级）

1. **严禁「不是……是……」类翻案句式**：
   - 「不是A，是B」（例：他不是害怕，是兴奋）
   - 「不是因为……而是……」「不是……，而是……」
   - 「与其说……不如说……」（同类翻案结构一并禁用）
   - 一切「否定 + 转折肯定」的对比翻案结构 → 一律改写为**直接陈述或动作描写**
2. **严禁「是……的」强调句式**（「他是很厉害的」「我是这么想的」）
3. **严禁「洗得发白」及其变体**

## 二、用词与计量硬指标（每章）

| 指标 | 要求 |
|---|---|
| 破折号 | **0**（严禁使用——） |
| AI 禁词 | **0**（含「不禁」「仿佛」「似乎」「显得」等高频 AI 腔词汇） |
| 禁用句式 | **0**（翻案句式、与其说、洗得发白、「是…的」强调） |
| 结尾钩子强度 | 1—10 级，**必须 ≥ 5 级** |
| 纯汉字数 | 1500—5000（以内容完整为优先；平台要求更严时从平台） |
| 对话与心理占比 | **50%—60%**（引号行、心理心声行 ÷ 总正文行） |
| 「像」字频次 | **≤ 10 次/章** |
| 超 150 字段落 | **0** |

## 三、文风要求

- 对话要带动作与神态，避免纯站桩对话。
- 视角黏性：一段内不随意切换视角。
- 直给动作与结果，少堆心理形容词。
- 爽点密集、开局快、高压断章收尾（番茄男频口径）。

## 四、AI 腔高频词（见到即换）

不禁 / 仿佛 / 宛如 / 似乎 / 显得 / 与此同时 / 总而言之 / 心中五味杂陈 /
眼中闪过一丝 / 嘴角勾起一抹 / 深吸一口气 / 缓缓开口 / 意味深长 / 不可置信 /
时间仿佛静止 / 他知道，从今以后 / 也许，这就是 / 这一刻，他明白了

处理办法：能删就删，不能删就换成**具体动作、感官细节或对话**。
